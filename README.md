# Brunch Crush

A mobile-friendly Candy Crush–style match-3 game built with plain HTML, CSS, and JavaScript — featuring **Coffee Beans**, **Bacon**, **Eggs**, **Avocados**, and **Chicken**.

## Features
- **5 Custom SVG Breakfast Pieces:** Sharp, consistent illustrated icons on both iPhone (iOS Safari) and Android (Chrome).
- **Classic Match-3 & Boosters:** Swipe or tap to match 3+, create Striped line clears (4-in-a-row), Sizzle Bombs (L/T shapes), Super Espresso Bombs (5-in-a-row), and combine specials.
- **100-Level Coffee Check:** Every 100 levels (100, 200, 300…), the game asks *"Did you have your coffee today?"*
  - **No:** Returns to Level 1 and reshuffles all levels with a fresh mix.
  - **Yes:** Unlocks the next 100 levels and keeps going.
- **Mobile Ready:** Tuned for iPhone 14 & Samsung Galaxy S25 with touch-swipe controls, Web Audio sound effects, haptic feedback, and automatic `localStorage` saving.

## Deploy on GitHub Pages
1. Upload the contents of this `brunch-crush` folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, pick `main` and `/ (root)`, then click **Save**.
4. Open the generated GitHub Pages URL directly on your iPhone or Android phone!
